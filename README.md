# Portfolio Personal — Edgar Edmundo Coronel Navarrete

Sitio web personal desarrollado como parte de la tarea de **Programación Avanzada**.

## 🌐 URL del sitio

**https://edgarcoroneln.github.io/Profesional_Personal_page/**

## 🛠 Stack

- HTML5 + CSS3 (Custom Properties) + JavaScript ES6+ vanilla
- Arquitectura SPA (Single Page Application)
- Hosting: GitHub Pages

## 🤖 Herramientas de IA utilizadas

- **Google Stitch** — Diseño visual "Executive Distinction" (paleta, tipografía, componentes)
- **Claude AI (Anthropic)** — Generación del código HTML/CSS/JS asistida por agentes IA
